Kinds:
- **SIM**: the lesson starts or tells the student to start that robot's simulation (`TURTLEBOT3_MODEL=…`, `ros2 launch <workspace package> …`, "choose **TurtleBot3 Waffle**" on the Simulator page). `ws:<id>` is a workspace package.
- **VIEWER**: an in-lesson RViz block (`"t": "rviz"`) shows that gallery robot (`"robot": "<id>"`).
- **FILE**: the lesson's RViz block edits the gallery robot's own file (`"path": "/robots/<that robot's file>"`).
- **GALLERY**: the RViz gallery block (`"gallery": true`); `robot` is only the first robot shown, the student can pick any.
- **LINK**: a link that opens `rviz.html?robot=<id>` (home page strip).
- **MENTION**: the id appears as a word in text, a file path or a URDF the lesson ships itself (not a use of the simulator robot).
